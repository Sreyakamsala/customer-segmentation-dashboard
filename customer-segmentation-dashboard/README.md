# Customer Segmentation Dashboard

## 📊 Project Overview
This project analyzes customer data to identify different customer segments based on premium contribution.

## 🔍 Key Insights
- Medium Value customers dominate the customer base
- Group policy type generates highest premium
- Low Value segment contributes least to revenue

## 🛠 Tools Used
- Power BI
- Data Cleaning & Transformation
- DAX (Calculated Column)
